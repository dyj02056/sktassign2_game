# 🛡️ 패킷 디펜더 (Packet Defender)

네트워크 보안의 핵심 개념을 게임으로 배우는 인터랙티브 시뮬레이터입니다.

🌐 **배포 URL**: https://sktassign2-game.vercel.app

---

## 🎯 30초 확인 방법

> **채점자/확인자를 위한 초간단 검증 가이드**  
> 아래 4가지만 확인하면 이 프로젝트의 핵심 요구사항을 모두 검증할 수 있습니다.

### ① 어디로 가나요?

| 항목 | 값 |
|------|-----|
| **접속 URL** | https://sktassign2-game.vercel.app |
| **계정 필요 여부** | ❌ 불필요 (로그인·인증·초대·비밀번호·OAuth·CAPTCHA 모두 없음) |
| **브라우저** | Chrome / Edge / Firefox 최신 버전 |
| **시크릿 창** | ✅ 시크릿 창에서도 동일하게 열림 (검증 완료) |
| **모바일** | ⚠️ PC 환경 기준 (1366×768 이상 권장) |

### ② 3단계 이내 무엇을 하나요?

| 단계 | 행동 | 예상 시간 |
|------|------|-----------|
| **1단계** | 위 URL 접속 → 시작 오버레이에서 **"🎮 클래식 모드"** 버튼 클릭 | 3초 |
| **2단계** | 화면 위에서 떨어지는 **빨강/주황/보라/노랑 패킷**을 마우스로 클릭하여 차단 | 10초 |
| **3단계** | **초록색 패킷**은 클릭하지 않고 통과시킴 | 5초 |

> 💡 **팁**: 초록 패킷을 잘못 클릭하면 오탐(-5점), 공격 패킷을 통과시키면 서버 피격(-10 HP)

### ③ 무엇이 보이면 통과인가요?

✅ **다음 5가지가 모두 보이면 통과입니다:**

| # | 확인 항목 | 어디서 보이나요 |
|---|-----------|----------------|
| 1 | 시작 화면에 **게임 규칙** (정상/공격 패킷 설명) | 시작 오버레이 |
| 2 | 시작 화면에 **핵심 조작** 안내 (마우스 클릭 = 차단) | 시작 오버레이 하단 |
| 3 | 상단 HUD에 **라운드·점수·누적·웨이브·HP** 실시간 표시 | 상단 좌측/중앙 |
| 4 | 공격 패킷 클릭 시 **점수 +10, 애니메이션, 사운드** 즉시 반영 | 즉시 반응 |
| 5 | **100점 도달 시 "🎉 라운드 N 클리어!"** 또는 **HP 0 시 "💀 라운드 N 실패!"** 화면 표시 | 15~25초 내 |

### ④ 안 될 때 무엇이 보이나요?

⚠️ **아래와 같은 증상이 보이면 문제가 있는 것입니다:**

| 증상 | 원인 | 해결 방법 |
|------|------|-----------|
| 화면이 **완전히 검은색** | JS 로드 실패 | `F12` → Console 탭에서 빨간 에러 확인 |
| 시작 버튼 **클릭해도 반응 없음** | 이벤트 미등록 | `F12` → Console에서 `is not defined` 에러 확인 |
| 패킷이 **안 떨어짐** | 게임 루프 미실행 | `requestAnimationFrame` 에러 확인 |
| 점수/HP가 **"NaN"** 으로 표시 | 저장값 손상 | `F12` → Application → Local Storage → Clear |
| **하얀 화면 + 404** | 배포 파일 경로 문제 | Vercel 배포 로그 확인 |
| **로그인 페이지로 리다이렉트** | Deployment Protection 활성 | Vercel Settings → Deployment Protection → Off |

## 🎮 게임 모드

### 1. 클래식 모드 (기본)
- 서버로 떨어지는 패킷을 분석하여 정상/공격 판별
- 정상 패킷은 통과, 공격 패킷은 클릭하여 차단
- **성공 조건**: 30초 안에 100점 획득 → 다음 라운드
- **실패 조건**: 서버 HP가 0이 되거나 30초 초과 시 패배
- **라운드마다 난이도 상승** (스폰 속도 ↑, 낙하 속도 ↑)

### 2. 암호화 모드
- 🔐 암호화된 패킷을 클릭하면 복호화 미니게임 실행
- 시저 암호로 인코딩된 패킷 내용을 4개 보기 중 선택
- 정답 판정 후 자동으로 차단/통과 처리

### 3. 로그 분석 모드
- 실제 서버 로그 스트림에서 위협 로그를 클릭하여 격리
- 30초 제한, 놓친 위협과 오탐 페널티
- 3라운드 최종 등급(S/A/B/C/D) 표시

### 4. 멀티플레이어 모드
- 2인용: 방어자 턴(30초) → 공격자 턴(30초)
- 방어자: 점수 극대화
- 공격자: 화면 클릭으로 공격 패킷 스폰

## 🏆 라운드 모드 (클래식)

**클래식 모드는 라운드 개념으로 무한 진행됩니다.**

### 라운드 진행 흐름

### 라운드별 난이도 상승

| 요소 | 변화 |
|------|------|
| **스폰 주기** | 라운드마다 -100ms (최소 350ms) |
| **낙하 속도** | 라운드마다 +0.2 (최대 4.0) |
| **목표 점수** | 항상 100점 (30초 내 도달 보장) |
| **제한 시간** | 라운드마다 30초 |
| **보스** | 5라운드마다 등장 |

### 라운드 클리어 화면

- **누적 점수** 표시 (라운드별 점수 합산)
- **"▶ 다음 라운드"** 버튼 → 난이도 상승 후 계속
- **"🏠 메인으로"** 버튼 → 시작 화면으로 복귀

### 저장되는 값

| 값 | 설명 |
|----|------|
| `pd.highscore` | 최고 **누적 점수** |
| `pd.highestRound` | 최고 도달 **라운드** |

## 🎯 핵심 기능

- **라운드 모드**: 성공 시 난이도 상승, 무한 도전
- **방화벽 규칙 시스템**: IP/포트/유형별 자동 차단 규칙 설정 (`F` 키)
- **파워업**: WAF 방화벽, 슬로우 모션, 더블 스코어
- **보스 라운드**: 5웨이브마다 등장하는 보스 격파
- **콤보 시스템**: 연속 차단 시 콤보 배수
- **교육 팁**: 게임 오버 시 실제 방어 기법 안내

## 🕹️ 조작법

| 키 | 기능 |
|---|---|
| 마우스 클릭 | 패킷 차단 / 로그 격리 / 파워업 획득 |
| `F` | 방화벽 규칙 창 열기 |
| `L` | 로그 분석 창 열기 |
| `P` | 일시정지 |
| `ESC` | 모든 모달 닫기 |

## 💾 저장 및 복구

### 📌 보존 대상으로 선언한 기록

다음 4가지 값은 **브라우저를 닫아도 유지**되며, 재접속 시 복원됩니다:

| 키 | 저장값 | 기본값 | 용도 |
|----|--------|--------|------|
| `pd.highscore` | 최고 누적 점수 (정수) | `0` | 사용자 최고 기록 |
| `pd.muted` | 음소거 상태 (true/false) | `false` | 사용자 설정 |
| `pd.totalGames` | 총 플레이 횟수 (정수) | `0` | 플레이 통계 |
| `pd.highestRound` | 최고 도달 라운드 (정수) | `1` | 최고 라운드 기록 |

### 📌 초기화 대상 (새 게임 시작 시)

다음 값들은 **매 게임 시작 시 초기값으로 리셋**됩니다:

- 현재 라운드의 점수, HP, 웨이브, 콤보
- 방화벽 규칙 (세션 내에서만 유지)
- 활성 파워업 상태

### 📌 안전성 보장

- **빈 저장값**: 위 4개 키에 값이 없으면 **기본값으로 시작** (게임 중단 없음)
- **손상 저장값**: `"abc"`, `"1e999"`, `"<script>"` 같은 값이 들어있어도 **기본값으로 폴백**
- **저장소 접근 불가**: 시크릿 모드·차단 환경에서도 **게임은 정상 실행**
